# stock-risk — 大盤環境 × 部位大小 × 移動停利

策略前提：右側動能／趨勢波段。這個 skill 不選股、不給目標價，只回答「能出手多少、錯了虧多少、對了怎麼抱」。

## 指令
```bash
python <skill_dir>/scripts/risk.py regime                            # 大盤環境
python <skill_dir>/scripts/risk.py size 2303 --entry 155 --stop 153  # 建議張數
python <skill_dir>/scripts/risk.py trail                             # 持倉 R 倍數與移動停利建議（只讀）
python <skill_dir>/scripts/risk.py exposure                          # 總持股 vs 建議上限
```
設定在 `assets/config.yaml`：總資金、每筆風險 %、單檔上限、流動性上限、大盤分級、移動停利規則。**只存本機，不同步。**

## 自動整合（不用手動呼叫）
- `stock-journal add`：有 `--falsify-price`（或 `--stop-init`）時自動算建議部位，實際超過 1.1 倍會提醒並寫進日誌。
- `stock-journal check`：每天盤後算移動停利並寫入 `trail_stop`（只上移）；防守價 `falsify_level` ＝ 固定證偽價、動態 MA、移動停利三者取最高。只有 MA 證偽的單，`stop_init` 會用進場日的 MA 補上。
- `stock-journal review`：多了 R 倍數統計（虧損是否守在 1R 內）。
- `stock-watch`：報告最上面一行是大盤環境；持倉欄顯示距「移動停利」或「證偽價」。

## 判讀規則（寫回覆時遵守）
1. **大盤環境**分數＝趨勢 4 項（站上 MA50、MA50 上升、站上 MA200、MA50>MA200）＋出貨日（25 日內 ≥4 天 −1、≥6 天 −2）＋漲跌家數（10 日上漲比 >55% +1、<45% −1）。≥4 多頭、2–3 震盪、≤1 空頭。出貨日是 O'Neil 的判法：指數跌 ≥0.2% 且成交金額大於前一日。
2. 大盤【空頭】時，掃出的強勢股也要降信心；不要因為個股漂亮就忽略環境。總持股超過建議上限要直說。
3. **部位**：1R 金額 ＝ 總資金 × 每筆風險 % × 大盤係數。三個上限（風險、單檔、流動性）取最小，報告要說是被哪個限制住。
4. 停損 < 0.75 ATR 要警告「易被正常波動洗掉」：不是叫使用者放寬停損，而是讓他知道被洗機率高；若放寬，部位會自動變小（風險金額不變）。
5. **移動停利**啟動門檻 ＝ 進場價 ＋ 1 × max(R, 0.75 ATR)，避免停損設極近時一點波動就被拉到成本。啟動後取 MA10 與「進場後最高收盤 − 3 ATR」較高者，且不低於成本。
6. 跌破移動停利出場，`journal close --reason 停利`；跌破原始證偽條件才是 `證偽`。兩者分開，檢討時才看得出「停損」與「停利」各自的紀律。
7. 長期持有（`longterm_types`）不做移動停利、不算 R，只計入總持股。
8. 融資部位的市值照算入總持股；使用者問槓桿時要提醒融資會放大 R 的實際虧損比例。

## 資料來源（全免費）
- 加權指數、個股日線：yfinance（經 stock-ta 資料層）；美元匯率 `TWD=X`
- 出貨日：證交所 FMTQIK（每日成交金額、指數漲跌），過去月份永久快取
- 漲跌家數：證交所 MI_INDEX（股票）＋ 櫃買每日彙總，逐日永久快取
- 大盤環境結果每日快取（15:00 前 30 分鐘更新一次）
