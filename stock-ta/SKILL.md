# stock-ta — 技術分析工具箱

## 模式選擇（先判斷再跑）

| 使用者說的話 | 模式 | 腳本 |
|---|---|---|
| 「掃一下」「快速看」「這幾支哪支強」、給 ≥2 個代號、只想要一個結論 | **快速** | `scripts/ta_quick.py` |
| 「精準」「深入」「完整」「進場點」「支撐壓力在哪」「籌碼」「法人」、要圖 | **精準** | `scripts/ta_precise.py` |
| 不明確 | 先跑快速；若旗標顯示有事（交叉、爆量、突破）再主動問要不要精準 | — |

快速模式約 1 秒/支且不打 FinMind；精準模式單支 5–15 秒，台股會多打 2 個 FinMind 請求（免費額度內）。

## 執行

```bash
# 快速（可多支）
python <skill_dir>/scripts/ta_quick.py 2330 2454 NVDA
python <skill_dir>/scripts/ta_quick.py 2330 --chart /tmp/2330.png

# 精準（單支，會產生 <out>.json / <out>.png / <out>_weekly.png）
python <skill_dir>/scripts/ta_precise.py 2330 --out /tmp/2330_ta
python <skill_dir>/scripts/ta_precise.py NVDA --out /tmp/nvda_ta --period 3y
```

**盤中呼叫一律加 `--drop-today`**（剔除今天未收盤的 K 棒，否則量比與均線會用半天資料算）。

代號規則：純數字視為台股（自動試 `.TW` 再 `.TWO`），其餘視為美股。首次執行若缺套件：`pip install yfinance mplfinance pandas numpy requests`。

## 解讀規則（寫報告時遵守）

1. **數字全部來自腳本輸出**，不憑印象補價位。JSON 裡沒有的就說沒有。
2. 三層標籤：`【事實】` = 腳本算出的價量／法人數字；`【推估】` = 你對型態、趨勢的判讀；`【市場預期】` 只在引用外部消息時用。
3. **不給目標價，給證偽條件**：每個多空看法後面要接「如果 X 發生，這個看法就錯了」（例如：跌破 MA20 且量縮 → 反彈論證失效）。
4. 訊號歷史勝率（`signal_history`）樣本 n < 8 時要明講「樣本太少，不可靠」。
5. 台股籌碼：投信連續買超天數、外資 20 日淨額、券資比是重點；融資 20 日增加但股價不漲 = 警訊，要點出。
6. 相對強弱 `vs_^TWII` / `vs_^GSPC` 為負，表示只是隨大盤漲，不要說「強勢」。
7. 不做左側交易建議（使用者風格）：沒有轉強證據時不建議「先買一點」。

## 快速模式輸出格式

一支 = 3–5 行；多支 = 一張表（代號｜收盤｜趨勢｜RSI｜KD｜量比｜旗標）+ 一句「值得再深挖的是哪支、為什麼」。

## 精準模式輸出格式

```
# <代號 名稱> 技術面 — <日期>
## 結論（一段，先講結論）
## 趨勢結構【事實】  日線 / 週線 / 均線排列 / 52 週位置
## 支撐壓力【事實＋推估】  三個支撐、三個壓力，附觸碰次數；籌碼密集區
## 量能與籌碼【事實】  量比、OBV 方向、（台股）法人、融資券
## 訊號統計【事實】  觸發的訊號 + 歷史 n / 勝率 / 均報酬
## 相對強弱【事實】
## 證偽條件【推估】  多方看法在什麼價位／狀況下失效；空方同理
```
