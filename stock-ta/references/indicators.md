# 指標定義與旗標

| 指標 | 參數 | 說明 |
|---|---|---|
| MA5/10/20/60/120/240 | 簡單均線 | 台股慣用 5/20/60（週／月／季線）；美股多看 50/200，本工具以 60/120 近似 |
| RSI14 | Wilder 平滑 | >70 超買、<30 超賣 |
| KD | RSV 9，K、D 各 3 平滑 | 台股慣用；<30 金叉、>70 死叉才列旗標 |
| MACD | 12/26/9 | 只看柱狀翻轉做旗標 |
| 布林 | 20 日、2σ | `BB_pos_pct` 0=下軌、100=上軌 |
| ATR14 | Wilder | 以 % 表示，用來訂停損距離（常用 2×ATR） |
| OBV | — | 精準模式判斷量價背離 |
| 量比 | 當日量 / 20 日均量 | >2 列「爆量」 |

## 結構
- 支撐壓力：±5 根 K 線的擺盪高低點，1.5% 內合併，≥2 次觸碰才算區。
- 籌碼密集區：近 250 日 volume-at-price 前 5 個價格帶。
- 訊號歷史：同一標的過去觸發同訊號後 5/20/60 日報酬與勝率；n<8 不可信。

## 台股 vs 美股
- 台股數字代號自動加 `.TW`，失敗改 `.TWO`（上櫃）。
- 台股法人單位為「張」，融資餘額為「張」；券資比 = 融券／融資。
- 美股沒有免費即時法人籌碼，精準模式不輸出 `tw_chips`。
