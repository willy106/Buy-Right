# stock-watch — 一鍵盯盤

前置：`stock-flow`、`stock-ta` 必須裝在同一個 skills 目錄（或設 `STOCK_TOOLBOX` 指向工具箱根目錄）。

## 執行
```bash
python <skill_dir>/scripts/watch.py                       # 用 assets/watchlist.yaml
python <skill_dir>/scripts/watch.py 2330 3017 6669        # 臨時加幾檔（與清單合併）
python <skill_dir>/scripts/watch.py --eod                 # 強制盤後版
python <skill_dir>/scripts/watch.py --out /tmp/watch.md --json /tmp/watch.json
```
腳本自己判斷交易時段；盤中約 30–45 秒（即時報價數批 + 各標的日線 + 短窗量比；當天首次會多花約 20 秒建同時段基準）。使用者只給代號沒說別的 → 直接跑，不要追問。

## 你要做的事（腳本印出報告後）
1. **先給 5 行以內的口頭結論**：資金在哪（真流入的族群 1–2 個）、自選標的裡誰在動、要注意什麼。再貼腳本產生的表。
2. 「真流入」的判準沿用 stock-flow：`share_vs_5d` > 0 且平均漲幅 > 0 且漲家 > 跌家；只漲不放量寫「跟漲」。
3. 自選標的的「族群流向」欄告訴你它所屬族群今天是被資金追還是被抽——個股漲但族群流出，要點出「孤軍」；個股跌但族群流入，點出「落後補漲候選」但不建議左側進場。
4. **放量／爆量看「短窗量比」**＝最近 N 分鐘量 ÷ 過去 20 日同時段均量（≥2 放量、≥3 爆量；窗口漲跌決定流入／流出／價平）。它反映「此刻」，已消除台股 U 型量能偏差。
   - 標 `*` 或來源 `yf~HH:MM` = 當天首次執行，用 yfinance 5 分 K，**延遲約 20 分**，要講明「這是 HH:MM 前的狀況」。每次執行都會存即時快照，15 分鐘內再跑一次就變成即時。
   - 「盤中異動」排行裡不在自選的標的，是這個功能的重點——點出最強 1–2 檔及其族群，同族群多檔同時爆量流入才算族群行情，單檔就是個股。
   - 爆量流入 ≠ 進場訊號：窗口漲幅小但量極大可能是換手或大單出貨，搭配族群流向與 stock-ta 判斷；不建議追。
   - 量比(換算) 是全日累計換算，只供參考、不觸發警示。
5. 警示區重複的（同一檔多條）合併成一行講。
6. 使用者追問某一檔或某族群 → 分別切到 `stock-ta` 精準模式或 `stock-flow`，不要在本 skill 內重跑。
7. 數字標籤：即時報價與盤後法人【事實】；盤中成交值、短窗量比、換算量比、族群 flow_score【推估】。

## 大盤環境（有裝 stock-risk 時）
報告第一行是大盤環境【多頭／震盪／空頭】與建議總持股。結論要先講環境：環境【空頭】時，盤中異動和族群流入都要降低信心，不要因為個股強就建議追。

## 與交易日誌整合
若裝了 `stock-journal`，未平倉部位會自動併入自選標的表的「日誌」欄（進場價、損益、距防守價多少；防守價是證偽價或移動停利，取較高者），跌破或逼近證偽價會進警示區。此時你的結論要先講持倉狀態，再講觀察標的。

## 設定檔
- `assets/watchlist.yaml`：分類 → 代號；使用者說「把 xxxx 加進持股／觀察」就直接改這個檔。
- `assets/alerts.yaml`：警示門檻、族群顯示數量、短窗量比（`surge_*`：窗口分鐘、放量／爆量倍數、流入流出漲跌門檻、排行張數下限）。

## 排程（使用者要「每天自動」時）
Claude Code 排程或 cron：`0 9,10,11,12 * * 1-5` 跑盤中，`35 15 * * 1-5` 跑 `--eod`（同時累積 stock-flow 的 5 日基準）。
想讓每次盯盤都拿到即時短窗量比：`58 8 * * 1-5` 背景跑 `stock-flow/scripts/flow_surge.py --watch --interval 60`（每分鐘存快照，13:31 自動結束）。
